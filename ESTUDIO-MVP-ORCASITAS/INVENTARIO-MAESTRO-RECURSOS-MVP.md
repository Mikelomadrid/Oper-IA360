# Inventario maestro de recursos del MVP

## Poblado Dirigido de Orcasitas

**Estado:** primera versión del inventario  
**Uso:** preparación de contenidos, base de datos y carga inicial en Lovable  
**Leyenda:**

- **Verificado:** confirmado en una fuente oficial o fuente primaria.
- **Identificado:** localizado en una fuente vecinal o secundaria; necesita contraste final.
- **Pendiente:** falta completar datos o confirmar vigencia.
- **P1:** debe aparecer en el primer lanzamiento.
- **P2:** recomendable para la primera ampliación.
- **P3:** contenido de crecimiento.

## 2. Campos que faltan por completar

Para cada ficha hay que completar, cuando proceda:

- nombre oficial;
- nombre usado por los vecinos;
- descripción;
- dirección completa;
- código postal;
- coordenadas;
- teléfono;
- correo;
- web;
- redes sociales;
- horario;
- servicios;
- accesibilidad;
- transporte cercano;
- imágenes;
- fuente principal;
- fecha de comprobación;
- estado de verificación;
- fecha de próxima revisión.

## 4. Criterio de publicación

No se publicará una ficha como definitiva si falta confirmar alguno de estos elementos:

- que el recurso sigue activo;
- dirección o ubicación;
- nombre correcto;
- fuente fiable;
- teléfono u horario cuando sean esenciales;
- derechos de las fotografías utilizadas.

Las fichas incompletas podrán mantenerse en estado interno `pendiente`, pero no deberán indexarse ni presentarse como información confirmada.
