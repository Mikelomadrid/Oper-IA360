# Prompt de rediseño visual para Lovable

## Portal local de Orcasitas — pasar de directorio a punto de encuentro

### Instrucción principal

El primer borrador no tiene el nivel visual ni editorial que necesita este proyecto. Debes rediseñar profundamente la interfaz y la maquetación.

No quiero que el resultado parezca:

- un listado de Google Maps;
- un directorio empresarial genérico;
- una plantilla administrativa;
- una cuadrícula de tarjetas sin jerarquía;
- una web municipal fría;
- una página hecha con componentes estándar colocados uno debajo de otro.

Quiero una web moderna, profesional, cálida y con identidad propia. El portal debe sentirse como **el lugar digital de encuentro del barrio**, no como un simple buscador de recursos.

---

## 1. Nueva idea de producto

El portal debe combinar cuatro sensaciones:

1. **Revista local:** historias, actualidad, memoria, fotografías y voces del barrio.
2. **Guía práctica:** servicios, colegios, salud, transporte, comercios y espacios.
3. **Plaza digital:** agenda, actividades, asociaciones y participación.
4. **Mapa vivo:** lugares, recorridos, comercios y puntos de interés.

La búsqueda y el directorio deben existir, pero no deben dominar visualmente toda la experiencia.

La home debe hacer que un vecino piense:

> “Aquí puedo enterarme de lo que pasa en mi barrio, descubrir sitios, conocer su historia y participar.”

---

## 2. Dirección de arte

### Personalidad

- Local.
- Humana.
- Editorial.
- Contemporánea.
- Cuidada.
- Cercana.
- Optimista.
- Con memoria, pero sin aspecto antiguo.

### Referencias de sensación

Inspírate en una mezcla de:

- revista cultural contemporánea;
- plataforma de guía urbana;
- publicación vecinal bien diseñada;
- agenda cultural local;
- web editorial premium;
- identidad de barrio renovada.

No copies ninguna web concreta. Utiliza únicamente la sensación general de calidad, ritmo editorial y pertenencia.

---

## 3. Paleta visual propuesta

Utiliza una paleta sobria y reconocible, con fondos cálidos y acentos controlados:

```text
Fondo principal:       #F6F3ED  marfil cálido
Fondo secundario:      #E8EFEA  verde grisáceo muy claro
Texto principal:       #202624  carbón
Verde identidad:       #1F5148  verde profundo
Terracota:             #C96E50  acento humano y urbano
Mostaza:               #D5A43B  acento puntual
Azul gris:             #5E8793  transporte y enlaces
Blanco:                #FFFFFF
Borde suave:           #D9DED8
```

Reglas:

- No utilices colores saturados en exceso.
- No uses un fondo blanco puro en toda la web.
- No conviertas cada categoría en un color estridente.
- Usa el verde profundo para navegación, acciones principales y confianza.
- Usa terracota y mostaza solo como acentos.
- Garantiza contraste AA para textos y botones.

---

## 4. Tipografía

Utiliza una combinación editorial y funcional:

- **Interfaz y navegación:** Manrope, DM Sans o una sans-serif equivalente.
- **Titulares editoriales:** una serif contemporánea como Source Serif 4, Lora o equivalente.

La tipografía debe crear contraste entre:

- información práctica;
- historias y actualidad;
- navegación y llamadas a la acción.

Evita utilizar una única tipografía genérica para todo.

---

## 5. Nueva home

La home debe ser una portada editorial y comunitaria, no un panel de búsqueda.

### Estructura recomendada

```text
┌─────────────────────────────────────────────────────────┐
│ ORCASITAS        Explorar  Agenda  Historias  Mapa      │
│                                   [Participar]          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  El barrio que      [imagen atmosférica del barrio]    │
│  compartimos                                           │
│  Guía, historias, actividades y lugares de Orcasitas.  │
│                                                         │
│  [Explorar el barrio]  [Ver qué pasa]                  │
├─────────────────────────────────────────────────────────┤
│ Ahora en el barrio                                      │
│ [Actividad]       [Noticia]          [Lugar destacado] │
├─────────────────────────────────────────────────────────┤
│ Descubre Orcasitas                                     │
│ [Poblado Dirigido] [Meseta] [Orca Sur]                 │
├─────────────────────────────────────────────────────────┤
│ Lo que necesitas hoy                                    │
│ Salud · Educación · Transporte · Deporte · Comercios   │
├─────────────────────────────────────────────────────────┤
│ Una historia del barrio                                 │
│ Imagen grande + texto editorial + [Leer historia]      │
├─────────────────────────────────────────────────────────┤
│ Agenda próxima                                          │
│ Fecha / actividad / lugar / organizador                │
├─────────────────────────────────────────────────────────┤
│ El mapa del barrio                                      │
│ Mapa visual + [Explorar todos los lugares]             │
├─────────────────────────────────────────────────────────┤
│ ¿Tienes algo que compartir?                             │
│ [Añadir actividad] [Corregir información]              │
└─────────────────────────────────────────────────────────┘
```

### Cambios obligatorios en la home

- El buscador no debe ser el héroe absoluto.
- El primer bloque debe transmitir identidad y pertenencia.
- Debe haber contenido editorial visible.
- Debe haber agenda o actividad.
- Debe haber historias y memoria.
- Debe haber una llamada a participar.
- El mapa debe aparecer como una experiencia, no como una simple incrustación técnica.

---

## 6. Navegación

La navegación principal debe ser corta y humana:

- **Explorar** — categorías, zonas y lugares.
- **Agenda** — actividades y eventos.
- **Historias** — memoria, actualidad e identidad.
- **Mapa** — exploración geográfica.
- **Participar** — enviar recursos, actividades, correcciones o fotografías.

El directorio puede existir como parte de “Explorar”, pero no debe ser necesariamente el nombre dominante de la web.

### Cabecera

- Logo tipográfico elegante.
- Nombre “Orcasitas” como protagonista.
- Subtítulo pequeño: “Guía, historias y vida de barrio”.
- Navegación con mucho espacio.
- Botón “Participar” destacado.
- Menú móvil limpio.

### Pie de página

Debe incluir:

- descripción breve del proyecto;
- enlaces de navegación;
- fuentes y actualización;
- contacto;
- participación;
- aviso legal y privacidad.

---

## 7. Componentes visuales

Sustituye la repetición de tarjetas genéricas por una jerarquía de componentes:

### Componentes editoriales

- Hero con imagen y titular.
- Historia destacada.
- Tarjeta editorial horizontal.
- Bloque de cita o voz vecinal.
- Timeline histórico.
- Agenda con fechas destacadas.

### Componentes prácticos

- Ficha compacta de recurso.
- Resultado de búsqueda.
- Etiqueta de categoría.
- Etiqueta de estado.
- Bloque de contacto.
- Bloque “cómo llegar”.
- Mapa contextual.

### Componentes comunitarios

- “Ahora en el barrio”.
- “Próximamente”.
- “Historias de vecinos”.
- “Comercios que forman parte del barrio”.
- “Participa y ayúdanos a mantenerlo actualizado”.

No todos los bloques deben tener la misma forma, tamaño o color. La variedad editorial es importante.

---

## 8. Página del Poblado Dirigido

Debe parecer una página de identidad y descubrimiento, no una ficha administrativa.

### Estructura

- Imagen principal del barrio.
- Texto de presentación.
- Mapa contextual.
- “Qué encontrarás aquí”.
- Lugares destacados.
- Plazas y espacios.
- Asociaciones.
- Historia resumida.
- Agenda.
- Acceso al directorio práctico.
- Llamada a participar.

### Tono de los textos

- cercano;
- claro;
- informativo;
- orgulloso sin ser propagandístico;
- respetuoso con la memoria vecinal.

---

## 9. Página de agenda

Crear una página de agenda aunque inicialmente tenga pocos eventos.

Debe incluir:

- calendario o selector de fechas;
- próximos eventos;
- categoría de actividad;
- lugar;
- organizador;
- enlace a más información;
- filtro por público: familias, mayores, cultura, deporte, comunidad.

La agenda es una de las piezas que convierte el portal en punto de encuentro.

---

## 10. Página de historias

Debe tener apariencia de revista local.

Secciones iniciales:

- Historia del Poblado Dirigido.
- Memoria vecinal.
- Calles y plazas.
- Rehabilitación y transformación.
- Fotografías históricas.
- Personas y asociaciones.
- Actualidad del barrio.

Diseño recomendado:

- imagen grande;
- titulares con serif;
- fechas visibles;
- categorías editoriales;
- lectura cómoda;
- enlaces a lugares del mapa relacionados.

---

## 11. Página de mapa

El mapa debe formar parte de una experiencia de exploración.

Debe permitir:

- ver lugares por categorías;
- filtrar por zona;
- abrir fichas resumidas;
- explorar recursos cercanos;
- alternar vista mapa/listado;
- destacar rutas o zonas de interés;
- enlazar a historias relacionadas.

No debe ser una pantalla vacía con un mapa genérico ocupando todo el espacio.

---

## 12. Diseño de fichas

Las fichas deben ser compactas, útiles y visualmente cuidadas.

### Ficha resumida

- imagen o color de categoría;
- nombre;
- tipo de recurso;
- zona;
- breve descripción;
- estado de verificación;
- botón “Ver ficha”.

### Ficha completa

- cabecera visual;
- nombre y categoría;
- descripción editorial breve;
- contacto;
- horario;
- mapa;
- cómo llegar;
- servicios;
- accesibilidad;
- fuente y fecha;
- recursos relacionados;
- botón de corrección.

No uses una larga columna de campos sin jerarquía visual.

---

## 13. Diseño de comercios

Los comercios deben integrarse en la vida del barrio, no parecer anuncios de pago.

Utiliza:

- fotografías reales cuando estén autorizadas;
- categorías claras;
- pequeños textos de contexto;
- zona o galería comercial;
- servicios principales;
- horarios;
- mapa;
- relación con otros lugares cercanos.

La futura monetización debe poder añadirse sin romper la confianza editorial.

---

## 14. Responsive y accesibilidad

### Móvil

- portada visual pero ligera;
- navegación inferior o menú claro;
- tarjetas a una columna;
- botones grandes;
- mapa accesible sin dominar toda la pantalla;
- contacto y cómo llegar siempre visibles.

### Escritorio

- composiciones asimétricas;
- bloques editoriales en dos columnas;
- mapa y listado en paralelo cuando tenga sentido;
- más aire y jerarquía visual.

### Accesibilidad

- contraste AA;
- foco visible;
- navegación por teclado;
- textos alternativos;
- etiquetas claras;
- tamaños legibles;
- no depender solo del color.

---

## 15. Qué debes eliminar del borrador actual

- colores genéricos o excesivamente brillantes;
- exceso de tarjetas iguales;
- apariencia de dashboard;
- bloques sin jerarquía;
- grandes listados como primera impresión;
- buscador como única propuesta de valor;
- iconos genéricos sin sistema visual;
- exceso de bordes redondeados;
- sombras fuertes;
- textos pequeños;
- apariencia de plantilla automática.

---

## 16. Qué debe conservarse

- datos reales del JSON;
- arquitectura SEO;
- categorías;
- mapa;
- buscador;
- fichas;
- estados de verificación;
- fuentes y fechas;
- formulario de participación;
- diseño responsive.

El rediseño es principalmente visual, editorial y de experiencia. No elimines la base funcional ni los requisitos SEO.

---

## 17. Resultado esperado

Entrega una nueva versión del MVP que parezca una plataforma local profesional y viva, con:

- identidad visual reconocible;
- portada editorial;
- sensación de comunidad;
- agenda;
- historias;
- mapa contextual;
- directorio integrado de forma natural;
- diseño responsive;
- fichas prácticas;
- arquitectura preparada para crecer.

La web debe responder visualmente a esta frase:

> “Aquí está la vida, la memoria y la información útil de Orcasitas.”

Antes de dar el rediseño por terminado, muestra una versión completa de la home, una página del Poblado Dirigido, una página de agenda, una página de historia, una página de categoría y una ficha individual para revisar la coherencia visual del sistema.
